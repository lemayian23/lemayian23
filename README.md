### `~$ whoami`

Software engineer from **Nairobi, Kenya** specializing in **retrieval-augmented generation** and full-stack products. I take AI systems end-to-end — document ingestion, chunking, vector embeddings, FAISS semantic search, cited LLM answers — and the React frontends that make them usable. My flagship RAG assistant runs **entirely on CPU** with **100% source citation**. Final-year B.Tech IT student at the Technical University of Kenya.

- 🔭 &nbsp;Currently building: a 10-capability local RAG platform — hybrid search, knowledge graphs, corrective retrieval, multi-tool agents
- 💼 &nbsp;Shipped for real businesses: CRM/ERP rewrite at Aquashine (450 files → Flask, 99.9% uptime), automation for a furniture platform and a retail shop
- 🛰️ &nbsp;Also building: **Lema-OS**, an x86_64 hobby operating system in C
- 🎯 &nbsp;Open to: junior software engineering / AI roles · contract RAG work · open source collabs
